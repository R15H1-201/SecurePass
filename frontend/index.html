SECURITY AWARENESS

Security insights

Simple habits that can significantly improve account security.

01

Use unique passwords

Use a different password for every account. Reuse can let one compromised account put others at risk.

02

Prefer long passphrases

Long, unpredictable passwords are generally harder to guess. Avoid quotes, names and predictable sequences.

03

Enable MFA

Multi-factor authentication adds another verification step beyond your password.

04

Use a password manager

A reputable password manager can create and store unique passwords for your accounts.

05

Watch for phishing

Check the website address carefully and avoid entering credentials after following unexpected links.

06

Change compromised passwords

If a service reports a breach or you suspect compromise, change the affected password and review MFA.

About SecurePass

ApplicationSecurePass
Version1.0.0
FrontendHTML, CSS, JavaScript
Backend FastAPI connected (generator settings only)
Password processingLocally in your browser

SecurePass does not store generated or analyzed passwords. Password generation and analysis happen locally in your browser. The FastAPI backend receives password-generation settings only, not the actual password. If you use the optional Have I Been Pwned breach check, only the first five characters of the password's SHA-1 hash are sent to its service. The remaining hash is compared locally in your browser. Your actual password is never sent to Have I Been Pwned.
